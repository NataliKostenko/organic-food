# Organic Food

A modern, responsive website for an organic food store built with HTML, Sass, and JavaScript.

## Features

- Responsive design that works on all devices
- Interactive product carousel using Glide.js
- FontAwesome icons for enhanced UI
- Clean, modern design with custom Sass styling
- Optimized build process with Gulp

## Technologies

- **HTML5** - Semantic markup
- **Sass/SCSS** - CSS preprocessor for maintainable styles
- **JavaScript** - Interactive functionality
- **Gulp** - Build automation and task runner
- **Glide.js** - Touch-enabled slider/carousel
- **FontAwesome** - Icon library

The website is deployed at <https://organicfood.kostenko.link/>
